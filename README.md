# Advance Dental Concepts

A new, original multi-page dental clinic website built from scratch.

## Stack
- Next.js App Router
- TypeScript
- CSS (custom responsive design)
- Lucide React icons

## Run locally
```bash
npm install
npm run dev
```

## Important content notes
Treatment information is patient education, not a diagnosis. Prices are the clinic-provided indicative PKR ranges and must be confirmed by the clinic before publication. Clinic address, phone, dentist credentials, ratings, reviews, real patient images, and booking integrations are intentionally left unclaimed until verified.
